# Preview fixture schema (v1)

The preview renderer (`tools/preview/server.rb`) renders a theme against one JSON file that describes a
whole store. The shape deliberately mirrors Shopify concepts (product CSV / Admin API), so
`catalog/catalog.json` can be converted to it 1:1 and the same data can feed `products.csv` and the
Admin API seed script.

Reference implementation: `tools/preview/fixtures/sample.json` (generated by `fixtures/make_sample.py`).

Conventions

- **Money is in cents** (integer): `24900` = €249,00. Strings with a decimal separator (`"249.00"`, `"249,00"`)
  and floats are accepted and converted, but integers are canonical.
- **Images** are file names relative to the images directory (`--images`, default `<fixture dir>/images`).
  Absolute `http(s)://` URLs are allowed but cannot be resized locally. Pixel size is read from the file
  header (PNG/JPEG/WebP/GIF); `width`/`height` may be given to override.
- **Handles** are Shopify handles (lowercase, `-`). If `handle` is omitted it is derived from `title`.
- **IDs** are optional. When omitted, stable numeric IDs are derived from the handle (Shopify-like 13–14
  digit numbers), so URLs like `?variant=` stay valid across restarts.
- Unknown keys are ignored, so the catalog may carry extra data (e.g. CSV-only columns).

## Top level

```jsonc
{
  "schema_version": 1,
  "shop": { ... },
  "products": [ ... ],
  "collections": [ ... ],
  "filters": [ ... ],            // storefront filters (Search & Discovery app config)
  "best_sellers": ["handle"],    // order used by sort "best-selling"
  "complementary": { "product-handle": ["other-handle"] },  // recommendations intent=complementary
  "menus": [ ... ],
  "pages": [ ... ],
  "blogs": [ ... ],
  "discounts": [ ... ],          // discount codes (Admin → Kortingen), optional
  "policies": { ... }
}
```

## shop

| key | type | Shopify concept |
|---|---|---|
| `name`, `email`, `phone`, `description` | string | Settings → Store details |
| `domain` | string | primary domain (preview uses the request host for URLs) |
| `currency` | ISO code | store currency (`EUR`) |
| `money_format` | string | `€{{amount_with_comma_separator}}` |
| `money_with_currency_format` | string | `€{{amount_with_comma_separator}} EUR` |
| `primary_locale` | string | default storefront language (`nl`) → theme uses `locales/nl.json` over the default locale file |
| `published_locales` | `[{iso_code, name, endonym_name, primary}]` | Languages; non-primary ones are served under `/<iso>/…` |
| `country` | ISO | shop country / default market country |
| `countries` | `[{iso_code, name, currency}]` | Markets countries (localization.available_countries) |
| `address` | `{address1, address2, city, zip, province, country, country_code, company, phone}` | store address |
| `taxes_included` | bool | prices include VAT (cart/product tax notes) |
| `customer_accounts_enabled` | bool | header account icon |
| `password_message`, `password` | string | password page message / preview password (default `preview`) |
| `payment_types` | string[] | `shop.enabled_payment_types` (ideal, bancontact, klarna, paypal, visa, master, maestro, apple_pay, google_pay, shopify_pay…) |
| `brand` | `{logo, square_logo, cover_image, slogan, short_description, colors}` | Brand settings (`shop.brand`) |
| `metafields` | metafield list | shop metafields |
| `all_collection_title` | string | title of the automatic `/collections/all` |
| `social_sharing_image` | image filename | Online Store → Preferences social sharing image (`page_image` fallback → og:image) |

## products[]

```jsonc
{
  "handle": "easy-up-partytent-premium",          // CSV Handle
  "title": "Easy-up partytent Premium",            // Title
  "body_html": "<p>…</p>",                         // Body (HTML)
  "vendor": "Merknaam",                            // Vendor
  "product_type": "Partytent",                     // Type
  "tags": ["easy-up", "partytent"],                // Tags (array or comma string)
  "status": "active",                              // only active products are rendered
  "published_at": "2026-03-02T10:00:00+01:00",
  "created_at": "2026-03-02T10:00:00+01:00",       // used by sort created-*
  "template_suffix": null,                         // product.<suffix>.json
  "gift_card": false,
  "seo": { "title": "…", "description": "…" },     // SEO Title / SEO Description
  "options": [                                     // Option1..3 Name + values (order = position)
    { "name": "Maat",  "values": [{ "name": "3x3" }, { "name": "3x4,5" }] },
    { "name": "Kleur", "values": [{ "name": "Wit", "swatch": { "color": "#F7F7F5" } },
                                  { "name": "Zwart", "swatch": { "color": "#1E1E1E", "image": "swatch-zwart.png" } }] }
  ],
  "variants": [{
    "id": 45000000000001,              // optional
    "sku": "EUP-33-WIT",               // Variant SKU
    "barcode": null,                   // Variant Barcode
    "option1": "3x3", "option2": "Wit", "option3": null,   // Option1..3 Value
    "price": 24900,                    // Variant Price (cents)
    "compare_at_price": 29900,         // Variant Compare At Price (cents, null = none)
    "inventory_quantity": 12,          // Variant Inventory Qty
    "inventory_management": "shopify", // Variant Inventory Tracker (null = not tracked → always available)
    "inventory_policy": "deny",        // Variant Inventory Policy (deny | continue)
    "weight": 18.0, "weight_unit": "kg",   // Variant Weight Unit; "grams" may be given instead
    "requires_shipping": true, "taxable": true,
    "image": "easy-up-premium-wit.png",    // Variant Image (must also be listed in images, or is appended)
    "quantity_rule": { "min": 1, "max": null, "increment": 1 },
    "unit_price_measurement": null,
    "metafields": []
  }],
  "images": [                          // Image Src / Image Position / Image Alt Text (first = featured)
    { "src": "easy-up-premium-wit.png", "alt": "Easy-up partytent in wit", "variant_skus": ["EUP-33-WIT"] }
  ],
  "metafields": [                      // product metafields (product.metafields.<ns>.<key>)
    { "namespace": "custom", "key": "materiaal", "type": "single_line_text_field", "value": "Aluminium" },
    { "namespace": "custom", "key": "usps", "type": "list.single_line_text_field", "value": "[\"A\",\"B\"]" }
  ]
}
```

- A product without `options`/`variants` gets Shopify's default `Title / Default Title` variant.
- Swatches: `swatch.color` (hex) and/or `swatch.image` (file) on option values = Shopify's option value
  swatches (`value.swatch.color`, `value.swatch.image`). They also drive swatch filter values.
- Variant availability follows Shopify: untracked → available; `continue` → available; else `inventory_quantity > 0`.

### Metafields

`metafields` may be a list of `{namespace, key, type, value}` or a map `{"ns.key": {type, value}}`.
`value` is the raw Admin-API string (lists and JSON as a JSON string). Supported types for typed `.value`:
`single_line_text_field`, `multi_line_text_field`, `rich_text_field` (Shopify rich-text JSON),
`number_integer`, `number_decimal`, `boolean`, `url`, `color`, `date`, `date_time`, `json`, `money`
(`{"amount":"12.50","currency_code":"EUR"}`), `dimension`/`weight`/`volume` (`{"value":..,"unit":..}`), `rating`,
`product_reference` / `collection_reference` / `page_reference` (handle or GID), `variant_reference` (id or GID),
`file_reference` (image file name), and `list.<any of these>`. `metafield_tag` renders them like Shopify.

## collections[]

```jsonc
{ "handle": "partytenten", "title": "Partytenten", "body_html": "<p>…</p>",
  "image": { "src": "banner-partytenten.png", "alt": "…" },
  "sort_order": "best-selling",         // manual | best-selling | alpha-asc | alpha-desc | price-asc | price-desc | created | created-desc
  "products": ["handle-a", "handle-b"],  // MANUAL collection (order kept)…
  "rules": [{ "column": "type", "relation": "contains", "condition": "tent" }],  // …or SMART collection
  "disjunctive": false,                  // smart: any rule (true) / all rules (false)
  "template_suffix": null, "seo": {}, "metafields": [] }
```

Smart rule columns: `title`, `type`, `vendor`, `tag`, `variant_price`, `variant_compare_at_price`,
`variant_inventory`, `variant_title`, `variant_weight`, `is_price_reduced`; relations: `equals`, `not_equals`,
`greater_than`, `less_than`, `starts_with`, `ends_with`, `contains`, `not_contains` (prices in euros, like
the admin). `/collections/all` exists automatically unless a collection with handle `all` is defined.

## filters[]

Storefront filtering configuration (Shopify Search & Discovery). Order = order shown.

```jsonc
[{ "source": "availability", "label": "Beschikbaarheid" },
 { "source": "price", "label": "Prijs" },
 { "source": "option", "name": "Kleur", "label": "Kleur" },          // filter.v.option.kleur
 { "source": "product_type" }, { "source": "vendor" }, { "source": "tag" },
 { "source": "metafield", "owner": "product", "namespace": "custom", "key": "materiaal", "label": "Materiaal" }]
```

## menus[]

```jsonc
{ "handle": "main-menu", "title": "Hoofdmenu", "items": [
  { "title": "Partytenten", "type": "collection", "handle": "partytenten", "items": [ /* nested, max 3 levels */ ] },
  { "title": "Over ons", "type": "page", "handle": "over-ons" },
  { "title": "Extern", "url": "https://example.com" } ] }
```

`type`: `collection | product | page | blog | article (handle "blog/article") | policy | search | frontpage |
catalog | collections | http` (or omit `type` and give `url`; type is inferred).

## pages[]

`{ "handle", "title", "body_html", "template_suffix" (e.g. "contact" → page.contact.json), "author", "published_at", "seo", "metafields" }`

## blogs[]

```jsonc
{ "handle": "nieuws", "title": "Tips & nieuws", "comments": "moderate",   // disabled | moderate | no_moderation
  "template_suffix": null,
  "articles": [{ "handle", "title", "author", "body_html", "summary_html", "image": {"src","alt"},
                 "tags": [], "published_at", "template_suffix", "metafields" }] }
```

## policies

Keys: `privacy_policy`, `refund_policy`, `shipping_policy`, `terms_of_service`, `contact_information`,
`legal_notice`, `subscription_policy` → `{ "title", "body_html" }`; served at `/policies/<handle>`.

## discounts[]

Discount codes, mapped to Shopify's code discounts (Admin API `discountCodeBasicCreate` /
`discountCodeFreeShippingCreate`). Applied with `POST /cart/update.js {"discount":"CODE,CODE2"}` or the
shareable link `/discount/CODE?redirect=/cart`. Codes are case-insensitive. Unknown codes, or codes whose
minimum is not met, show up as `{"code","applicable":false}` in `cart.discount_codes`, like Shopify.

```jsonc
{ "code": "WELKOM10", "title": "10% welkomstkorting",
  "value_type": "percentage",          // percentage | fixed_amount (value in cents) | free_shipping
  "value": 10,
  "target_selection": "all",           // all = order discount (cart.cart_level_discount_applications)
                                        // entitled = product discount (line_item.line_level_discount_allocations)
  "allocation_method": "across",       // fixed_amount + entitled: each (per unit) | across (split once)
  "entitled_products": ["handle"], "entitled_collections": ["handle"], "entitled_variants": [id],
  "target_type": "line_item",          // shipping_line for free-shipping codes (applicable, nothing allocated in the cart)
  "minimum_subtotal": 5000,            // cents, optional
  "minimum_quantity": 2,               // optional
  "status": "active" }                 // expired = treated as unknown
```

## CSV mapping (for the catalog phase)

| Shopify product CSV column | fixture |
|---|---|
| Handle | `products[].handle` |
| Title / Body (HTML) / Vendor / Product Category / Type / Tags / Published / Status | `title` / `body_html` / `vendor` / (n/a) / `product_type` / `tags` / `published_at` / `status` |
| Option1..3 Name, Option1..3 Value | `options[].name`, `variants[].option1..3` |
| Option1 Linked To / swatches | `options[].values[].swatch` |
| Variant SKU / Grams / Inventory Tracker / Inventory Qty / Inventory Policy | `sku` / `weight`+`weight_unit` / `inventory_management` / `inventory_quantity` / `inventory_policy` |
| Variant Price / Compare At Price (decimal) | `price` / `compare_at_price` (cents) |
| Variant Requires Shipping / Taxable / Barcode / Variant Image | `requires_shipping` / `taxable` / `barcode` / `image` |
| Image Src / Image Position / Image Alt Text | `images[]` (order = position) |
| SEO Title / SEO Description | `seo.title` / `seo.description` |
| `<label> (product.metafields.ns.key)` | `metafields[]` |
| Gift Card / Template suffix | `gift_card` / `template_suffix` |
